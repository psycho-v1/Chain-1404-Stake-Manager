How to use

  1. Tap Connect in the header. Pick your wallet or open this site inside a dapp browser. It stays connected until you tap Disconnect.
  2. If asked, add BlockDAG Community (chain 1404).
  3. Connect your wallet. The page lists every staking-contract position it can find for that wallet, with staked amount and yield. It does not select one for you. Tap Use this position only when you want to act on that row.
  4. Home then streams staked / rewards / unbonding every 12 seconds.
  5. Stake, unstake, or claim from Actions. Buttons stay off until you choose one listed position and the contract allows the send.
  6. Watch Insights for mix, week clock, and unbonding bars.
  7. If the header pill asks you to review a contract, open More → Contracts before sending more coins.
  8. Feature idea or a bug? Open More → Contact and write @psycho_v1 on Telegram.
  9. Stuck send? Use KEDGE.

Timing

  • Rewards accrue after the stake confirms. The live bar is the first-claim / unbond clock, not an APY.
  • First claim wait is about 4 weeks from first deposit.
  • Unstake wait is about 3 weeks, then Claim.
  • Weeks follow the 7-day contract clock.

Before / after the split

  • Home now shows three books: last shared block 316,001, live community, live divergent.
  • Staking did not exist at block 316,001. Pre-split is native wallet balance only.
  • Unstake and claim default to the community ledger. A divergent send only makes sense if you have already pointed the wallet RPC at that family. Both books use chain ID 1404, so the wallet can only aim at one RPC at a time.
  • More → Audit builds a downloadable text record of your position and the public case chronology.

If rewards or unbonding stay at zero

  • The staking contract address is not a position. Use a listed position row — the one that already shows your yield.
  • Wrong wallet, or the position lives on a different pool.
  • A position with yield 0 is still listed if principal is there. Adding more to a zero-yield position does not move coins to a position that already pays.
  • RPC still checking — wait for Network OK in the header.
