# Chain-1404 Stake Manager

Community UI for BDAG staking on chain **1404**.
Not staking.blockdag.engineering. No custody. Community RPCs only.

## Pages
Home, Stake, Unstake, Claim, Insights, Activity log, Contracts, Guide, Safety.

## Wallet
Header Connect uses EIP-6963 plus injected dapp-browser wallets
(MetaMask, Rabby, Trust, TokenPocket, SafePal, OKX, Bitget, Coinbase, Brave, Binance).

## Migrations
If the live implementation or owner drifts from the pin, sends pause.
Accept a reviewed upgrade or add a new proxy on the Contracts page.

## Pins
See `js/pins.js`. Denied hosts: bdagscan.com, blockdag.works.
